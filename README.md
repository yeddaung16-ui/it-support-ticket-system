# IT Support Ticket System

A web-based IT support ticket management system built with Python, Flask, SQLite, HTML, and CSS.

## Project Overview

This project simulates an internal IT support portal where users can create support tickets and IT staff can manage them.

The goal of the project is to demonstrate practical IT support, Python development, database, web development, and Git skills.

## Features

- Create IT support tickets
- Set ticket priority
- Track ticket status
- Update ticket status
- Search tickets
- Filter tickets by status
- Dashboard ticket statistics
- SQLite database storage
- Input validation
- Responsive web interface

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- Git
- GitHub
